# SaaSify – Modern SaaS Frontend

A premium, multi-page SaaS startup frontend built using HTML, CSS, JavaScript, and Bootstrap 5.

## Features
- Modern UI/UX
- Dark mode with LocalStorage
- Countdown timer
- Search & filtering
- Form validation
- Responsive design

## Tech Stack
- HTML5
- CSS3
- JavaScript
- Bootstrap 5

## Deployment
Deploy easily using GitHub Pages.
